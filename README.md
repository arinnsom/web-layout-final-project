# Финальная практическая работа по модулю «Веб-верстка» (Skillbox)

Комплексный проект по оптимизации, рефакторингу и адаптации веб-страниц перед выходом в релиз. Работа построена на основе реального коммерческого сценария: устранение багов по обратной связи от тестировщика и доведение интерфейса до идеального соответствия макетам.

## Демо-версия проекта
arinnsom.github.io/web-layout-final-project/

Примечание: при запуске демо-версии сайта открывается страница Блог(index.html), для перехода на страницу article.html необходимо нажать на карточку в блоге с заголовком "Как стать идеальным кандидатом на собеседовании ..."

---

## Используемый стек технологий
* **HTML5** — семантическая разметка (использование тегов `<header>`, `<nav>`, `<main>`, `<footer>` и др.)
* **CSS3 / SCSS** — блочная модель, использование препроцессора для декомпозиции стилей и работы с переменными
* **Flexbox & Grid Layout** — построение гибких сеток и карточных интерфейсов
* **Методология БЭМ** — независимая, расширяемая структура именования CSS-классов
* **Адаптивная верстка (Responsive Design)** — плавная адаптация страниц под различные разрешения экранов (Desktop, Tablet, Mobile)
* **Pixel Perfect / Figma** — точное соответствие шрифтов, отступов и графических элементов дизайн-макету

---

## Реализованный функционал и особенности
* Полная верстка страниц «Главная/Блог» (`index.html`) и страницы статьи (`article.html`)
* Интерактивные элементы: стилизованные кнопки, карточки товаров, эффекты наведения (hover-эффекты) и фокуса
* Оптимизированное подключение сторонних шрифтов и иконок
* Поддержка favicon для различных платформ и мобильных операционных систем
* Retina-ready: растровые изображения подготовлены и оптимизированы для экранов с повышенной плотностью пикселей (2х)
* Использованы подходящие форматы (JPG, PNG, SVG), векторные изображения объединены в SVG-спрайт
* Код отформатирован, структурирован и успешно прошёл проверку через HTML- и БЭМ-валидаторы
